# QAQMOON

這是我的個人網站原始碼倉庫：

https://qaqmoon.github.io/

本站使用 Astro 建置，並基於開源主題 [Mizuki](https://github.com/LyraVoid/Mizuki) 做個人化整理與改造。

這不是 Mizuki 官方倉庫，也不是模板展示站。Mizuki 只作為本站的視覺與技術基底。

## 目錄說明

- 文章：`src/content/posts/`
- 關於頁：`src/content/spec/about.md`
- 站點設定：`src/config/`
- GitHub Pages 部署：`.github/workflows/pages.yml`
