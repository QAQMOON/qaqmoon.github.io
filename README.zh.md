# QAQMOON

这是我的个人网站源码仓库：

https://qaqmoon.github.io/

本站使用 Astro 构建，并基于开源主题 [Mizuki](https://github.com/LyraVoid/Mizuki) 做了个人化整理和改造。

这不是 Mizuki 官方仓库，也不是模板演示站。Mizuki 只作为本站的视觉和技术底座使用。

## 目录说明

- 文章：`src/content/posts/`
- 关于页：`src/content/spec/about.md`
- 站点配置：`src/config/`
- GitHub Pages 部署：`.github/workflows/pages.yml`
