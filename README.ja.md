# QAQMOON

このリポジトリは QAQMOON の個人サイトのソースコードです。

https://qaqmoon.github.io/

このサイトは Astro で構築され、オープンソーステーマ [Mizuki](https://github.com/LyraVoid/Mizuki) をベースに個人用に調整しています。

これは Mizuki の公式リポジトリではありません。Mizuki は個人ブログのデザインと技術基盤として利用しています。

## Notes

- Posts: `src/content/posts/`
- About page: `src/content/spec/about.md`
- Site config: `src/config/`
- GitHub Pages workflow: `.github/workflows/pages.yml`
