# QAQMOON

This repository contains the source code for my personal website:

https://qaqmoon.github.io/

The site is built with Astro and customized from the open-source [Mizuki](https://github.com/LyraVoid/Mizuki) theme.

This is not the official Mizuki repository. Mizuki is used here as a visual and technical foundation for a personal blog.

## Notes

- Blog posts live in `src/content/posts/`.
- The about page lives in `src/content/spec/about.md`.
- Site configuration lives in `src/config/`.
- GitHub Pages deployment is handled by `.github/workflows/pages.yml`.
